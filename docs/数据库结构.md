# 数据库结构说明

数据库文件：`data/class_assignment.db`（SQLite 3）

---

## 表概览

| 表名 | 用途 | 随仓库自带的演示数据量 |
|------|------|------------------------|
| `students` | 学生账号与班级信息 | 266 条（已脱敏） |
| `preferences` | 志愿填报记录 | 265 条 |
| `admins` | 管理员账号 | 2 条（演示账号） |
| `settings` | 系统设置（填报时间等） | 3 条 |
| `sessions` | 登录会话 | 0 条（已清空） |
| `operation_logs` | 管理员操作日志 | 0 条（已清空） |

---

## students — 学生表

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PK | 自增主键 |
| `student_id` | TEXT UNIQUE | 学号，登录账号。演示数据格式：`2026` + 6 位序号 |
| `name` | TEXT | 姓名（演示数据为随机生成） |
| `password` | TEXT | 密码，**明文存储**。演示数据统一为 `123456` |
| `major` | TEXT | 专业大类：`大数据` / `云计算`，决定数据隔离与可选方向 |
| `class_name` | TEXT | 当前班级，如 `大数据技术1班` |
| `original_class` | TEXT | 原行政班级 |
| `first_login` | INTEGER | `1` = 首次登录需强制改密码，`0` = 否 |
| `created_at` | TEXT | 创建时间 |
| `gender` | TEXT | `男` / `女` |
| `failed_attempts` | INTEGER | 连续登录失败次数，达到 5 次锁定 |
| `locked` | INTEGER | `1` = 已锁定 |
| `status` | TEXT | `active` / 其他 |

> 生产环境建议：把 `password` 改为 bcrypt 哈希存储。

---

## preferences — 志愿表

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PK | 自增主键 |
| `student_id` | TEXT UNIQUE | 学号（外键关联 `students.student_id`），一名学生一条记录 |
| `choice1` | TEXT | 第一志愿方向名 |
| `choice2` | TEXT | 第二志愿 |
| `choice3` | TEXT | 第三志愿 |
| `choice4` | TEXT | 第四志愿（可为空） |
| `updated_at` | TEXT | 最后更新时间 |

### 五个分流方向

**大数据专业（3 个）**
- 大数据VR方向
- 大数据分析运维
- 大数据应用开发

**云计算专业（2 个）**
- 云计算运维与安全
- 新媒体技术方向

> 业务规则：学生只能在本专业对应的方向内排序，禁止跨专业选择。

## settings — 系统设置表

| key | 演示值 | 说明 |
|-----|--------|------|
| `start_time` | `2026-01-01T00:00:00` | 填报开始时间 |
| `end_time` | `2027-12-31T23:59:00` | 填报截止时间 |

可在管理员端「时间设置」页面修改，无需手动改库。

## 常用 SQL

```sql
-- 各方向第一志愿人数
SELECT choice1, COUNT(*) AS cnt
FROM preferences
WHERE choice1 IS NOT NULL
GROUP BY choice1
ORDER BY cnt DESC;

-- 分专业填报进度
SELECT s.major,
       COUNT(s.student_id) AS total,
       COUNT(p.student_id) AS submitted
FROM students s
LEFT JOIN preferences p ON s.student_id = p.student_id
GROUP BY s.major;

-- 未填报学生名单
SELECT s.student_id, s.name, s.class_name
FROM students s
LEFT JOIN preferences p ON s.student_id = p.student_id
WHERE p.student_id IS NULL;

-- 批量重置所有学生密码为 123456
UPDATE students SET password = '123456', first_login = 0, failed_attempts = 0, locked = 0;

-- 清空所有志愿（重新开放填报时用）
DELETE FROM preferences;

-- 清空会话（强制所有人重新登录）
DELETE FROM sessions;
```
